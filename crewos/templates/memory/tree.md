# Memory Tree — 跨项目永久记忆

> 这个目录是一个 Obsidian 兼容 vault(用 Obsidian 直接打开 `~/.crewos/memory` 即可)。
> CC(总指挥)接新任务前先在这里检索同类经验,结案时把复盘写进 projects/。
> 第二个项目从此吸取第一个项目的教训——越用越聪明。

## 结构

- `projects/` — 每个项目一个文件:目标、做法、踩坑、结论
- `knowledge/` — 全局知识:可复用方法、风格指南、模型选型经验

## 写入约定

- 一个文件一个主题,标题用 `# `,日期写绝对日期
- 用 `[[文件名]]` 互相链接(Obsidian 双链)
- 复盘格式:背景 / 做了什么 / 踩了什么坑 / 下次怎么做
