为什么是 CREWOS

多模型异构 × 实时可视化 × 风险分级自动化 —— 市面上没有第二个

🧠

贵模型决策,便宜模型执行

CEO(Claude)只做分析、拆解、派单、审阅,绝不亲自执行。coder/writer/researcher 等 7 个角色各绑一个最划算的专属模型,一人一脑,角色纯粹。

🔁

CEO 审阅循环

产出不合格就给出具体修改意见重派,最多 3 轮;仍不达标自动上报给你,附分析与建议。打回原因自动写入该角色的错题本。

⚠️

L0-L4 风险分级

全自动无边界,风险越大汇报越大:读取静默、内部写入日志、外部只读通知、可逆外部写倒计时放行、不可逆操作阻塞等你批准。

📚

越用越聪明

错题本随每次派单注入角色上下文;Memory Tree(Obsidian 兼容 vault)沉淀跨项目经验 —— 第二个项目吸取第一个项目的教训。

🛰️

宁死不降级

模型挂了换通道不换模型(同模型多 Provider failover);全部通道不可用就挂起上报,绝不静默换模型丢失角色记忆。

⛽

成本实时追踪 + 熔断

每个 token 入账:按角色、按模型、按任务实时聚合;单任务预算熔断,超限挂起上报。评估集自动生长,模型胜任度一表看清。

三分钟上岗

与 Hermes / OpenClaw 同款安装体验,所有数据住在 ~/.crewos

# 1. 安装
git clone https://github.com/spikesubingrui-design/CrewOS.git && cd CrewOS
bash install.sh

# 2. 初始化(API keys 可全部回车跳过,稍后在看板配置)
crewos onboard

# 3. 启动 Mission Control(自动打开浏览器)
crewos start

# 4. 让 Claude Code 上岗当总指挥
claude mcp add crewos -- crewos mcp
01

打开看板:轨道视图实时直播谁在干活、谁在审阅、谁挂了、钱花在哪。

02

CONFIG 里给每个乘组换脑(换 LLM 不丢记忆)、设预算熔断、配飞书推送、编辑动作风险表与定时任务。

03

对 Claude Code 说"帮我研究 X"——它按手册派单、审阅、复盘,风险动作先来问你。
